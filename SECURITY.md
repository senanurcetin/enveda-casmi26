# Security and research data handling

Do not include API tokens, Kaggle credential files, cloud keys, source spectra or private molecular records in issues, logs, notebooks or commits. Local credential files and generated data are ignored by Git. Rotate exposed credentials with the issuing service.

For a confidential vulnerability, use the repository's GitHub private vulnerability reporting feature if available. If unavailable, request a private contact channel from the maintainer without posting exploit details or secrets publicly.

The dashboard is a static historical research view with no authentication, paid endpoint or private-data API. Optional BigQuery tools are operator-run and outside the default zero-cost workflow. This code is not an independently validated chemical identification service.
