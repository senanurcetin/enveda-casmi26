# Contributing to CASMI26 research

Keep this project noncommercial, English-first and reproducible without paid infrastructure. Preserve historical logs and frozen input artifacts. Explain any changed model assumption and include a regression that fails for the original defect.

Separate implementation evidence, synthetic tests and actual data-dependent results. New scientific conclusions require immutable source manifests, matched molecule/spectrum identities, appropriate controls, uncertainty and an untouched evaluation population. Never overwrite historical scores with unexecuted estimates.

Run the checks in [reproducibility](docs/guides/reproducibility.md). Update the model/data cards and evidence ledger when their claims change. Kaggle publication maintenance must not invoke competition submission automation. Do not commit licensed spectra, model artifacts, credentials or notebook outputs containing source records.
